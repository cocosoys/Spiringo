# 用户模块教程

用户模块提供用户 CRUD、密码哈希、默认管理员创建，并通过命名依赖向认证模块提供用户能力。

## 1. 复制代码

复制模块代码：

```text
internal/modules/user/
  user.go
  migrations.go
  dto/
  model/
  repository/
  service/
  handler/
```

必须先复制或实现：

```text
internal/modules/tenant/
internal/core/module/
internal/core/di/
internal/core/event/
internal/pkg/orm/
pkg/types/
```

如果还要接入登录注册，继续复制 `internal/modules/auth/`。

## 2. 复制依赖

用户模块需要：

```bash
go get github.com/gin-gonic/gin
go get github.com/google/uuid
go get golang.org/x/crypto
go get gorm.io/gorm
```

`golang.org/x/crypto` 用于密码哈希相关能力。

## 3. 启用配置

在 `configs/config.yaml` 中配置：

```yaml
modules:
  user:
    enabled: true
    default_admin:
      enabled: true
      username: "admin_%s"
      password: "changeme"
      email_template: "admin@%s.spiringo"
      nickname: "System Admin"
```

`username` 和 `email_template` 中的 `%s` 会用租户标识替换，适合每个租户创建独立管理员。

## 4. 注册模块

用户模块依赖租户模块：

```go
application.RegisterModules(
    tenant.NewTenantModule(),
    user.NewUserModule(),
)
```

用户模块内部声明：

```go
module.NewBaseModule("user", "tenant")
```

框架会先初始化 `tenant`，再初始化 `user`。

## 5. 数据迁移

用户模块迁移 ID：

```text
user_001_create_users_table
```

迁移内容：

```go
m.migrateDB.AutoMigrate(&model.User{})
```

执行：

```powershell
$env:GOARCH='amd64'
$env:CGO_ENABLED='1'
go run ./cmd/spiringo migrate up -env development -config configs
```

## 6. HTTP 接口

路由前缀：

```text
/api/v1/user
```

接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/user` | 分页查询用户 |
| `POST` | `/api/v1/user` | 创建用户 |
| `GET` | `/api/v1/user/:id` | 查询单个用户 |
| `PUT` | `/api/v1/user/:id` | 更新用户资料 |
| `DELETE` | `/api/v1/user/:id` | 删除用户 |

创建用户请求：

```json
{
  "username": "alice",
  "email": "alice@example.com",
  "phone": "13800000000",
  "password": "secret123",
  "nickname": "Alice"
}
```

更新用户请求：

```json
{
  "email": "alice.new@example.com",
  "phone": "13900000000",
  "nickname": "Alice New",
  "avatar": "https://example.com/avatar.png",
  "status": "active"
}
```

`status` 支持：

```text
active, disabled
```

## 7. 与认证模块集成

用户模块在初始化时会把 `UserService` 注册为认证模块需要的命名依赖：

```go
app.DI.ProvideNamed("auth_user_service", m.svc)
```

认证模块通过下面方式读取：

```go
userSvc, err := di.ResolveNamed[service.UserServiceInterface](app.DI, "auth_user_service")
```

因此复制用户和认证模块时，注册顺序建议保持：

```go
tenant.NewTenantModule(),
user.NewUserModule(),
auth.NewAuthModule(),
```

## 8. 默认管理员机制

用户模块订阅 `tenant.created` 事件后，会根据 `default_admin` 配置为新租户创建管理员。

适用场景：

- SaaS 平台创建租户后自动生成初始管理员。
- 内部系统开通组织后自动生成组织管理员。

上线建议：

- 生产环境不要使用默认密码 `changeme`。
- 初始密码应通过安全渠道发送或要求首次登录强制修改。
- 默认管理员邮箱模板要符合真实域名规则。

## 9. 事件应用

用户模块会发布：

```text
user.created
user.updated
user.deleted
```

可用于：

- 审计日志。
- 搜索索引同步。
- 通知管理员。
- 清理用户缓存。

## 10. 常见问题

- 登录接口找不到用户：检查用户模块是否先于认证模块初始化，并确认 `auth_user_service` 已注册。
- 多租户用户列表为空：检查 `X-Tenant-ID` 是否正确。
- 默认管理员没有创建：检查 `modules.user.default_admin.enabled`，并确认租户创建事件已发布。
