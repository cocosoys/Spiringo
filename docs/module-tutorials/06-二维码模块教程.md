# 二维码模块教程

二维码模块提供二维码生成、图片解析、短链跳转、扫码记录和统计能力；可独立返回 PNG，也可接入对象存储生成图片 URL。

## 1. 复制代码

复制模块代码：

```text
internal/modules/qrcode/
  qrcode.go
  migrations.go
  dto/
  model/
  repository/
  service/
  handler/
```

同时复制基础设施：

```text
internal/modules/tenant/
internal/core/module/
internal/core/di/
internal/pkg/orm/
internal/pkg/storage/
pkg/types/
```

`internal/pkg/storage` 是可选依赖；如果目标项目不需要对象存储，可保留接口但不启用 storage 配置。

## 3. 启用配置

```yaml
modules:
  qrcode:
    enabled: true
    default_size: 256
    default_level: "M"
    oss_prefix: "qrcode/"
    bucket_name: ""
```

纠错级别支持：

```text
L, M, Q, H
low, medium, high, highest
```

推荐：

- 普通业务二维码使用 `M`。
- 需要嵌入 Logo 时使用 `Q` 或 `H`。
- 图片尺寸保持 256 到 512，避免过大影响传输。

## 4. 注册模块

```go
application.RegisterModules(
    tenant.NewTenantModule(),
    qrcode.NewQRCodeModule(),
)
```

依赖声明：

```go
module.NewBaseModule("qrcode", "tenant")
```

## 6. HTTP 接口

路由前缀：

```text
/api/v1/qrcode
```

接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/v1/qrcode/generate` | 生成二维码 |
| `POST` | `/api/v1/qrcode/parse` | 解析二维码图片 |
| `GET` | `/api/v1/qrcode/s/:code` | 短链跳转或返回内容 |
| `GET` | `/api/v1/qrcode/stats/:code` | 查询扫码统计 |

## 7. 生成二维码

JSON 响应：

```http
POST /api/v1/qrcode/generate
Content-Type: application/json
```

```json
{
  "content": "https://example.com/invite/abc",
  "size": 256,
  "level": "M",
  "foreground_color": "#000000",
  "background_color": "#ffffff",
  "logo_url": "",
  "logo_size": 64
}
```

直接返回 PNG：

```text
POST /api/v1/qrcode/generate?format=image
```

响应字段：

```json
{
  "id": "<record id>",
  "content": "https://example.com/invite/abc",
  "short_code": "<short code>",
  "image_url": "<optional url>",
  "short_url": "<optional short url>"
}
```

## 8. 解析二维码

支持三种输入方式。

方式一：multipart 上传：

```text
POST /api/v1/qrcode/parse
Content-Type: multipart/form-data
field: image
```

方式二：传入图片 URL：

```json
{
  "image_url": "https://example.com/code.png"
}
```

方式三：传入 base64：

```json
{
  "image_base64": "data:image/png;base64,..."
}
```

限制：

```text
最大图片大小：5MB
URL 仅允许 http:// 或 https://
```

## 9. 短链与统计

短链访问：

```text
GET /api/v1/qrcode/s/:code
```

如果二维码内容是 URL，接口会返回 302 跳转；如果不是 URL，则返回 JSON 内容。

统计查询：

```text
GET /api/v1/qrcode/stats/:code
```

响应：

```json
{
  "short_code": "abc123",
  "scan_count": 12,
  "content": "https://example.com/invite/abc"
}
```

扫码日志会记录 IP、User-Agent、用户 ID 和租户 ID。

## 10. 对象存储接入

启用对象存储：

```yaml
storage:
  enabled: true
  type: "minio"
  minio:
    endpoint: "127.0.0.1:9000"
    access_key: "<access key>"
    secret_key: "<secret key>"
    use_ssl: false

modules:
  qrcode:
    oss_prefix: "qrcode/"
    bucket_name: "public-assets"
```

模块初始化时会尝试从 DI 中读取：

```go
di.Resolve[storage.Storage](app.DI)
```

存在 storage 实例时，生成结果可以保存为对象并返回 `image_url`。

## 11. 在其他模块中复用

二维码服务暴露生成器和短链服务接口，业务模块可按接口依赖：

```go
type InviteService struct {
    qr service.Generator
}
```

适用场景：

- 邀请链接二维码。
- 支付二维码。
- 设备绑定二维码。
- 活动签到二维码。

## 12. 常见问题

- 解析失败：确认图片小于 5MB，且二维码清晰。
- 生成图片没有 URL：检查对象存储是否启用；未启用时可用 `format=image` 直接拿 PNG。
- 短链不跳转：确认 content 是否以 `http://` 或 `https://` 开头。
- 统计没有增加：确认访问的是 `/api/v1/qrcode/s/:code`，不是直接访问原始图片。
