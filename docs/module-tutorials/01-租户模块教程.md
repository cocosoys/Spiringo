# 租户模块教程

租户模块负责租户 CRUD、租户状态、租户策略和租户事件，是用户、认证、RBAC、支付、二维码等模块的隔离基础。

## 1. 复制代码

复制模块代码：

```text
internal/modules/tenant/
  config.go
  tenant.go
  migrations.go
  dto/
  model/
  repository/
  service/
  handler/
```

同时确保基础设施存在：

```text
internal/core/module/
internal/core/di/
internal/core/event/
internal/pkg/orm/
pkg/types/
```

## 2. 复制依赖

租户模块直接依赖 Gin、GORM、UUID 和项目内部 ORM/事件能力：

```bash
go get github.com/gin-gonic/gin
go get github.com/google/uuid
go get gorm.io/gorm
```

如果目标项目还没有数据库驱动，按实际数据库添加一个：

```bash
go get gorm.io/driver/mysql
go get gorm.io/driver/postgres
go get gorm.io/driver/sqlite
```

## 3. 启用配置

在 `configs/config.yaml` 中启用：

```yaml
modules:
  tenant:
    enabled: true
    strategy: "shared_db"
```

支持的策略：

| 策略 | 含义 | 当前使用建议 |
| --- | --- | --- |
| `shared_db` | 所有租户共用同一个数据库，通过 `tenant_id` 隔离 | 默认推荐 |
| `schema` | 每个租户使用独立 schema | 适合 PostgreSQL 等 schema 能力强的数据库 |
| `database` | 每个租户使用独立数据库连接 | 适合强隔离 SaaS，但运维成本更高 |

## 4. 注册模块

在 `internal/modules/builtin/builtin.go` 中注册：

```go
application.RegisterModules(
    tenant.NewTenantModule(),
)
```

其他依赖租户的模块必须声明依赖：

```go
module.NewBaseModule("user", "tenant")
```

## 5. 数据迁移

租户模块迁移 ID：

```text
tenant_001_create_tenants_table
```

迁移内容：

```go
m.migrateDB.AutoMigrate(&model.Tenant{})
```

执行迁移：

```powershell
$env:GOARCH='amd64'
$env:CGO_ENABLED='1'
go run ./cmd/spiringo migrate up -env local -config configs
```

## 6. HTTP 接口

路由前缀：

```text
/api/v1/tenant
```

接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/v1/tenant` | 分页查询租户 |
| `POST` | `/api/v1/tenant` | 创建租户 |
| `GET` | `/api/v1/tenant/:id` | 查询单个租户 |
| `PUT` | `/api/v1/tenant/:id` | 更新租户名称、域名、状态 |
| `DELETE` | `/api/v1/tenant/:id` | 删除租户 |

创建租户请求：

```json
{
  "name": "演示租户",
  "code": "demo",
  "strategy": "shared_db",
  "domain": "demo.example.com"
}
```

更新租户请求：

```json
{
  "name": "演示租户新版",
  "domain": "new-demo.example.com",
  "status": "active"
}
```

`status` 支持：

```text
active, suspended, expired
```

## 7. 请求头接入

租户上下文可由中间件从请求头注入：

```text
X-Tenant-ID: <tenant id>
X-Tenant-Name: demo
X-Tenant-Strategy: shared_db
X-Tenant-DB-Conn: <optional connection string>
```

业务服务内可通过 `pkg/types` 读取上下文中的租户信息：

```go
tenantID := types.GetTenantID(ctx)
```

## 8. 事件应用

租户模块会发布租户事件：

```text
tenant.created
tenant.suspended
tenant.activated
```

典型应用：

- 用户模块订阅 `tenant.created` 后创建默认管理员。
- 通知模块订阅 `tenant.suspended` 后发送站内信或 Webhook。
- 审计模块订阅所有租户事件后写入审计日志。

## 9. 常见问题

- 创建用户或支付单没有租户隔离：检查请求头是否带了 `X-Tenant-ID`。
- 依赖租户的模块被跳过：检查 `modules.tenant.enabled` 是否为 `true`。
- 多租户数据串租户：检查 repository 是否使用 `orm.NewTenantDB(db)` 而不是直接使用裸 `db`。
